# 赞助

TidyMate 目前没有商业化计划，也没有接受赞助。这一页是占位，用来提前说清楚
"如果有人想支持，钱会花在哪、不会换来什么"。

## 如果将来接受赞助

资金只会用于这些方向，按优先级排列：

1. **兼容性验证的硬件与时间**：不同 Windows 版本、不同文件系统（NTFS/exFAT/ReFS）、
   OneDrive 与网盘同步目录、企业策略环境下的实测。
2. **回收站与 Shell 接口的实测**：`send2trash` 还原能力边界、`IFileOperation` 行为差异。
3. **签名证书**：减少 SmartScreen 与杀软误报的固定成本。
4. **文档与翻译**。

## 不会发生的事

- 不会因为赞助而优先合并某个功能，尤其是降低删除/覆盖安全性的功能。
- 不会提供"赞助版才有的自动清理"。
- 不会引入遥测来"证明投入产出"。

## 其他支持方式（当前唯一有效）

- 用 `scripts/make-sandbox.ps1` 造沙箱，跑真实场景，把**脱敏后的**失败案例提成 issue。
- 在你的机器上验证长路径、OneDrive、企业策略环境，回报结果。
- 帮忙 review 触碰写盘逻辑的 PR。

这份文档本身也需要维护。如果你发现这里写的和实际行为不一致，那就是一个 `P1` 缺陷。
